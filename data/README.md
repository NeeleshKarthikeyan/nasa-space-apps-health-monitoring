# data/ (owner: Jayden, with Fahim on NASA data)

| Path | What it is | Committed? |
| --- | --- | --- |
| `generate_crew.py` | Simulates 4 astronauts x 60 days with planted scenarios | yes |
| `fetch_nasa.py` | Downloads real NASA data ONCE and saves it to `nasa_snapshots/` | yes |
| `validate.py` | Checks `raw/` output against the contract, writes `processed/` | yes |
| `raw/` | Untouched generator output | yes (small) |
| `nasa_snapshots/` | Untouched NASA downloads, never edited by hand | yes |
| `processed/crew_daily.csv` | Validated file everyone else reads | yes |

## Rules
- Fix the random seed so everyone gets identical data.
- Never edit files in `raw/` or `nasa_snapshots/` by hand; change the script and re-run.
- Missing reading = empty cell, never 0.

## Planted scenarios (the `scenario` column)
| Label | Astronaut | Days | Signals that move |
| --- | --- | --- | --- |
| `normal` | all | most days | none beyond noise |
| `fatigue_spe` (hero) | B | 44 to 50 | sleep down, resting HR up, reaction time up, mood down, radiation spike |
| `solar_event` | A, C, D (B keeps `fatigue_spe`) | 46 to 47 | radiation x10 (placeholder size); timing modelled on a real DONKI event |
| `bone_muscle` | C | 20 to 60 | body mass and exercise drift down |
| `cardio_drift` | D | 30 to 40 | resting HR and systolic BP up, HRV down |
| `exercise_trap` | A | 25 (1 day) | HR and exercise minutes up on a heavy workout day: should NOT alert |

## What is real vs simulated

**Everything in `crew_daily.csv` is simulated.** Real astronaut medical records are not public,
and NASA does not publish a continuous stream of crew health telemetry. The astronauts (A to D),
their baselines and all health signals are fictional and were generated by `data/generate_crew.py`
with a fixed random seed. Baseline values are plausible simulation values, not medical references.

| Item | Real or simulated | Source / note |
| --- | --- | --- |
| 4 astronauts x 60 days of daily health signals | Simulated | `data/generate_crew.py` |
| Personal baselines and day-to-day noise | Simulated | Chosen to differ per astronaut |
| Health problems (fatigue, bone and muscle loss, cardio drift, exercise trap) | Simulated | Planted on known days; labelled in the `scenario` column |
| Sensor gaps (~1%) | Simulated | Left empty on purpose, never filled in |
| Base radiation rate (~0.5 mGy/day) | Simulated placeholder | Not a sourced value |
| Timing of the solar event (days 46 to 47) | Modelled on a real event | NASA DONKI solar energetic particle episode of 9 to 13 May 2024 (14 records; reference event `2024-05-11T02:10:00-SEP-001`, GOES-P >100 MeV). Mission days are fictional. |
| Size of the solar event dose (x10) | **Simulated placeholder** | DONKI gives event times, not astronaut doses |
| `cumulative_dose_mgy` | Simulated | Running total of `radiation_mgy` (mGy). Renamed from `cumulative_dose_msv` because the values are absorbed dose in mGy, not dose equivalent in mSv. |

### Sources
- NASA DONKI (Space Weather Database Of Notifications, Knowledge, Information) API: https://api.nasa.gov
  - Snapshot used: `data/nasa_snapshots/donki_sep_2024-05.json`
  - Reference event: https://ccmc.gsfc.nasa.gov/DONKI/view/SEP/30714/-1

### Limits
This is a prototype for demonstration. It does not diagnose medical conditions. It flags
deviations from each astronaut's own normal pattern.
